# Курсовая работа №1: Приложение для анализа банковских операций

## Описание:
Приложение для анализа транзакций, которые находятся в Excel-файле (data/operations.xlsx. предпочтительно) 
Приложение генерирует JSON-данные для веб-страниц, формирует Excel-отчеты, а также предоставляет другие сервисы.

## Установка:
Клонируйте репозиторий:
git clone https://github.com/dariamakurova/COURSE_PROJECT_1

## Использование

Приложение позволяет:

- получить JSON-ответ на указанную дату, содержащий следующие сведения:
    -- приветствие в зависимости от времени суток
    -- топ-5 транзакций по расходам
    -- курсы валют (настройки пользовательских валют располагать в data/user_settings.json)
    -- котировки компаний из S&P500 (настройки пользовательских котировок располагать в data/user_settings.json)
- реализовать простой поиск по транзакциям в описании и категории по заданному слову
- получить транзакции с тратами в заданной категории
